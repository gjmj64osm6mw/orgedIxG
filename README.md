# 项目简介

## 核心功能
- 实时车辆检测：基于YOLOv8的高精度车辆识别
- 多目标追踪：使用DeepSORT算法实现稳定的车辆追踪
- 虚拟线统计：支持自定义虚拟线进行车流量统计
- 区域监控：多边形区域的进出监控功能
- 热力图分析：可视化车辆活动密度分布
- 车速估算：基于双虚拟线的速度测量功能
- 数据报告：生成Excel/PDF格式的专业分析报告
- 实时统计：提供多维度的实时数据统计功能

## 适用场景
- 智能交通监控系统
- 车流数据分析与规划
- 城市交通管理
- 车辆行为研究
- 交通拥堵分析
- 停车场管理系统

## 技术特点
- 基于YOLOv8深度学习模型的车辆检测系统
- 采用DeepSORT算法实现多目标追踪
- 支持多种视频和图片输入格式
- 提供实时数据可视化和统计功能
- 可生成专业格式的数据报告
- 集成CUDA加速推理能力（可选）
